## Design Context

### Users

AI process operators who use c8c as a daily-driver tool. They run 3+ active flows simultaneously, switch between them, approve gates, attach capabilities. The interface must work on day 30 of usage, not impress on the first screenshot. Solo founders with AI agents, no employees.

### Brand Personality

Calm, Legible, Capable. Human-aware but not cute. Technical but not cold. Powerful but not overloaded. Serious but not enterprise-theater. Manus is the reference for chat-first flow execution.

### Aesthetic Direction

- **Visual tone**: Minimal, precise, tool-like. Every element earns its space.
- **Theme**: Dark mode primary, CSS custom properties for theming.
- **References**: Manus (chat-first UX, task cards above input), Linear (sidebar density, keyboard-first).
- **Anti-references**: Notion (too playful), Retool (too enterprise), generic AI chat UIs (too simple).
- **Motion**: Restrained, purposeful. No bounce, no elastic. Calm deceleration (`ease-standard`, `ease-emphasis`). Existing tokens: 140ms fast, 170ms base, 220ms slow.

### Design Principles

1. **Status at a glance** — User understands flow state within seconds: current step, outcome, next decision.
2. **UI elements over text** — Shipped UI closes jobs through compact elements, not text-heavy narratives.
3. **One figure per state** — Only the primary object gets card treatment. Everything else is flat ground.
4. **Keyboard-first** — Frequent actions have shortcuts. Shortcuts accelerate the same IA, not a parallel product.
5. **Progressive disclosure by familiarity** — First run explanatory, repeat runs compact. Explanations collapse after understanding.
